# Danyal Khan — Cybersecurity Portfolio

A responsive, modern, dark navy + electric blue portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. For editing, open the folder in VS Code.

## Before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with your public contact email.
- Replace `https://github.com/YOUR_GITHUB` with your GitHub profile URL.
- Add verified project links and update skill progress only when you can support the claims with completed work.
- Check all content and contact details before making the site public.

## Deploy free
You can publish this static site using GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.

## Customize
- Colors and layout: `style.css`
- Content and sections: `index.html`
- Mobile menu and current year: `script.js`

The project uses Google Fonts from an external CDN. The site itself does not require a backend or API key.
